# UNIT001 OS — Agent Rules

Before developing any interface, read `/design-system` and the relevant documentation in `/docs`.

Do not introduce local arbitrary design values when they are not defined by the global system.

## UNIT001 Design System v0.1

`/design-system/tokens/UNIT001_TOKENS_0.1.json` and
`/design-system/spec/UNIT001_GRID_SYSTEM_0.1.svg` are the **SOURCE OF TRUTH**
for UNIT001 Design System v0.1.

Before developing the website, pages, components, or any other digital interface,
read these specifications.

Do not independently change **LOCKED** values. **CANDIDATE** values may be
tested, but every change must be explicitly documented.
